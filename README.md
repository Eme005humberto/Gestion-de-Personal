# Gestion-de-Personal
Esta es una aplicación Web desarrollada en Java con el objetivo de poder ingresar la información de nuestros empleados y llevar un mejor control de ellos.💻✔

=== Stack tecnologico ===

1 - Java
2 - Servlets
3 - JSP 
4 - MVC
5 - Maven
6 - SweetAlerts 
7 - Bootstrap
8 - TomCat v9.0
